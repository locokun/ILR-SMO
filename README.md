# ILR-SMO

Official repository for **[ILR-SMO: Iterative Latent Refinement for Robust Spatial Multi-Omics Integration](https://doi.org/10.24963/ijcai.2026/582)**, published at **IJCAI-ECAI 2026**.

**Authors:** Anqi Yu, Xudong Xu, Jianzhi Lu, Yuqi Sun, Bingguo Chen, Chenxi Ma, Weimin Tan, and Bo Yan.

ILR-SMO introduces iterative latent refinement for robust spatial multi-omics integration.

**Publication:** Proceedings of the Thirty-Fifth International Joint Conference on Artificial Intelligence, pp. 5227–5235, 2026.
